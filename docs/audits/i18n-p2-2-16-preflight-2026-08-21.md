## 7. taskTypeLabel() leak — independent proof

### Function definition

`frontend/src/rental/lib/service-task-semantics.ts`:

```typescript
export function taskTypeLabel(task: Pick<ApiTask, 'type' | 'metadata' | 'category'>): string {
  // ...
  return TASK_TYPE_LABEL_DE[task.type] ?? task.type.replace(/_/g, ' ');
}
```

`TASK_TYPE_LABEL_DE` is a hardcoded German map (e.g. `VEHICLE_SERVICE → 'Fahrzeug-Service / Wartung'`).

### Canonical localized alternative already exists

`frontend/src/rental/components/tasks-settings/tasks-i18n.ts`:

```typescript
export function taskTypeLabel(locale: string, type: ApiTaskType): string {
  return tt(locale, TASK_TYPE_KEYS[type]);
}
```

Uses existing `tasks.type.*` keys (14 types, EN/DE complete).

### Concrete EN-path example

For `task.type === 'VEHICLE_SERVICE'`:

| Path | Locale | Output |
|------|--------|--------|
| `service-task-semantics.taskTypeLabel(task)` | EN UI | **`Fahrzeug-Service / Wartung`** (German) |
| `tasks-i18n.taskTypeLabel('en', 'VEHICLE_SERVICE')` | EN UI | **`Vehicle service`** (English) |

Reproduced in `VendorOperationalTasks.tsx` line 58: `{taskTypeLabel(task)}` — imports legacy function, no locale parameter.
