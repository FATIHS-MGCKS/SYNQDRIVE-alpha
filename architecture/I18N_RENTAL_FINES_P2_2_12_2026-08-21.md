## i18n architecture

- React surfaces use `useLanguage().t()` from canonical `frontend/src/i18n/LanguageContext`.
- `fines-i18n.ts` holds machine constants (`FINE_STATUS_VALUES`, `FINE_OFFENSE_TYPE_VALUES`) and presentation resolvers (`labelFineStatus`, `labelFineOffenseType`, `formatFineDate`, `formatFineAmount`).
- Offense `<select>` uses German machine values as `option` values; labels resolve via `fines.offenseType.*` keys.
- Reused keys: 11 legacy `fines.*`, `common.back/cancel/save/edit`, `tasks.filter.status.*` for linked task chips.
- New presentation namespace: `fines.filters.*`, `fines.form.*`, `fines.detail.*`, `fines.status.*`, `fines.offenseType.*`, `fines.metric.*`, `fines.col.*`.
