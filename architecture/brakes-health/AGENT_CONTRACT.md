# Brakes Health — Agent Contract (bootstrap)

Substantive brake **wear algorithm**, persistence, or API contract changes require an updated authority when registry status is `AUDIT_IN_PROGRESS` or `AUTHORITY_ACTIVE`.

**DS4 migration:** Do not switch brake recalculation to DS4-derived rates without **PR-8** and documented Fable review (health-affecting numeric use).

Consult [`drivingintelligence/design/DS4_AUTHORITATIVE_ASSESSMENT_MIGRATION.md`](../drivingintelligence/design/DS4_AUTHORITATIVE_ASSESSMENT_MIGRATION.md) before cross-module Driving Impact changes.
