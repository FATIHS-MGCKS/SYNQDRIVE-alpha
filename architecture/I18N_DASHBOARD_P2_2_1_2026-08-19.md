# I18N Rental Dashboard P2.2.1

**Date:** 2026-08-19

## Decision

P2.2.1 extracts user-facing copy from the Rental Dashboard scope into canonical `frontend/src/i18n/translations/{en,de}.ts` keys. Builders and display mappers use `dashboard-i18n.ts` (`dt`, `dashboardFormattingLocale`); React surfaces prefer `useLanguage().t()` where practical.

## Helper

`frontend/src/rental/components/dashboard/dashboard-i18n.ts`:

- `dt(locale, key, vars?)` — non-React copy for builders/utils
- `dashboardFormattingLocale(locale)` — replaces inline `de-DE` / `en-US` toggles in touched dashboard files

## Key namespaces

- `dashboard.*` — labels, counts, drilldown, fleet, operations, insights, handover, CTA
- `notification.*` — affected vehicles, issue copy, time semantics, CTAs (reused where identical)
- `vehicle.status.*` — operational status labels in fleet rows
- `common.*` — close, details, today (reused)

## Migrated scope

All listed dashboard builders, runtime slice builders, notification copy helpers, and dashboard React panels/drawers under `frontend/src/rental/components/dashboard/`.

Shim imports in touched dashboard files point at `../../../i18n/` (canonical runtime), not `rental/i18n`.
